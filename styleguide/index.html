Styleguide Sïana

Une forme, un SVG. La couleur ne vit plus dans le fichier : color-* peint la forme, text-* peint le texte via currentColor.

Couleurs

Primary est noir, secondary est blanc. Les cinq teintes de la palette remplacent l’un ou l’autre selon la classe.

  • Primary#000000color-primary
  • Secondary#ffffffcolor-secondary
  • Pourpre#3e1f24color-pourpre
  • Crème#f5e0cbcolor-creme
  • Terracotta#ae6868color-terracotta
  • Indigo#a19ebbcolor-indigo
  • Corail#fb907ccolor-corail

Signes

Le tracé utilise fill="var(--primary)". Sans classe, primary vaut #000000.

Logos

Les lettres utilisent toujours fill="currentColor". Le cadre, quand il existe, utilise fill="var(--secondary)", blanc par défaut.

Cartes

Même principe : le fond suit secondary, le dessin et les lettres suivent currentColor.
