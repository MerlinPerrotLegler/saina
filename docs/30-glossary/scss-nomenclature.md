# scss-nomenclature

Le SCSS spécifique se déclare **dans** les SFC Vue (`<style lang="scss">`) ou fichiers `app/**/*.scss` adjacents aux composants. Jamais sous `docs/` ni dans l’API PHP.

Une spec UI pose `scss_namespace` (ex. `c-checkout`) et liste les `.vue` / `.scss` dans `code_paths`. Voir [[TOKENS]] pour les primitives Tailwind, [[GUIDELINES]] pour la règle, [[EDGES]] pour `STYLES`.

_À figer (préfixes, BEM, etc.)._
