# style-de-bijou

Résultat du quiz : l’univers joaillier qui correspond aux réponses, pas une étiquette de personne.

## Définition

Quatre styles, noms neutres et mixtes :

- [[style-chaleureux]]
- [[style-elegant]]
- [[style-sensible]]
- [[style-instinctif]]

Formulation attendue : « Ton style est chaleureux. » ou « Votre style de bijou est chaleureux. » Le registre (tu / vous) doit être unique sur tout le parcours.

## Ne pas confondre avec

- Un type de personnalité (« vous êtes une personne chaleureuse »).
- Un résultat genré (« La Chaleureuse », « L’Élégante », « La Sensible », « L’Instinctive »).

Le détail des questions, du score et des textes de résultat est dans [[fsd-quiz-style]].
